# Technical Articles Shared with the Community

During my participation in the **First Cloud AI Journey (FCAJ)** program, I explored AWS technologies and shared technical articles with the [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj) community. These articles focus on practical AWS topics, including Amazon Bedrock cost management, budget monitoring, API protection, and resource usage control in Generative AI applications.

Below are four technical articles shared with the community:

---

### [Blog 1: 5 Steps to Manage Amazon Bedrock Costs: Beyond Simply Reducing Token Usage](3.1-blog1/)

- **Topic:** Amazon Bedrock, Generative AI & Cost Optimization
- **Summary:** Introduces a five-step approach to managing Amazon Bedrock costs, covering cost attribution, token usage monitoring, budget controls, resource optimization through Intelligent Prompt Routing and Prompt Caching, and continuous performance evaluation.

---

### [Blog 2: Why Can Your AWS Bill Exceed a $10 Budget?](3.2-blog2/)

- **Topic:** AWS Budgets, Budget Monitoring & Cloud Cost Management
- **Summary:** Explains the difference between budget alerts and actual spending limits on AWS. Demonstrates how AWS Budgets, Budgets Actions, Cost Anomaly Detection, and Cost Explorer can work together to monitor spending, detect anomalies, and reduce unexpected expenses.

---

### [Blog 3: Why Does an API Still Need Throttling When AWS WAF Is Already Enabled?](3.3-blog3/)

- **Topic:** AWS WAF, API Gateway, Rate Limiting & API Security
- **Summary:** Explores how AWS WAF and API Gateway Throttling complement each other to filter unusual traffic, control request rates, and protect AWS Lambda. Also discusses direct API Gateway access risks and monitoring through Amazon CloudWatch.

---

### [Blog 4: Amazon Bedrock: Controlling Requests and Token Usage Before Costs Increase](3.4-blog4/)

- **Topic:** Amazon Bedrock, API Security, Token Usage & Cost Optimization
- **Summary:** Introduces a layered architecture for controlling requests and enforcing per-tenant token quotas using AWS WAF, API Gateway, Lambda, and DynamoDB. CloudWatch, SNS, S3, and Athena support usage monitoring, alerting, and analysis to help reduce unexpected AI application costs.
