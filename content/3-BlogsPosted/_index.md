# Community Technical Blogs

During my internship in the **First Cloud AI Journey (FCAJ)** program, I actively published technical articles in the [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj) community. These articles summarize real-world cloud engineering challenges, architectural design patterns, and hands-on optimization techniques learned throughout my journey.

Below are the 3 technical articles published:

---

### [Blog 1: Least Privilege Security with Amazon EKS Pod Identity & Session Policies](3.1-blog1/)
* **Topic:** Kubernetes Cloud Security & Identity Federation
* **Summary:** Explores the modern Amazon EKS Pod Identity mechanism, explaining how session policies enable granular, dynamic IAM permission scoping per pod without proliferating dozens of individual IAM roles. Helps DevOps and Platform engineers enforce least privilege cleanly at scale.

---

### [Blog 2: High-Performance Static Web Hosting with S3 & CloudFront Origin Access Control (OAC)](3.2-blog2/)
* **Topic:** Web Performance, Edge Caching & Perimeter Security
* **Summary:** A step-by-step architectural breakdown of hosting high-speed frontend applications on Amazon S3 while blocking all direct public access using Origin Access Control (OAC), SSL termination, HTTP/3 acceleration, and smart cache invalidation strategies.

---

### [Blog 3: Event-Driven Serverless Image Processing with S3, Lambda & DynamoDB](3.3-blog3/)
* **Topic:** Serverless Computing & Asynchronous Architectures
* **Summary:** Walkthrough on building a resilient, asynchronous media processing pipeline. When media files land in an S3 bucket, event notifications instantly trigger lightweight AWS Lambda functions for automated compression and metadata persistence in Amazon DynamoDB.
